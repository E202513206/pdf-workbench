PDF를 N쪽마다 여러 파일로 나누는 방법

하나의 긴 PDF를 일정한 쪽수로 쪼개거나 원하는 위치에서 나누는 방법입니다.

구분선이란?

작업대의 쪽 사이에 넣는 가위(✂) 표시입니다. 구분선으로 나뉜 묶음 하나가 결과 파일 하나가 됩니다. 결과가 2개 이상이면 ZIP 파일로 한 번에 내려받습니다.

방법 1. N쪽마다 자동으로 나누기

  1. PDF를 올리고 “전체 추가”로 작업대에 모두 올립니다.
  2. 구분선 영역에서 숫자를 입력합니다(예: 5).
  3. “넣기”를 누르면 5쪽마다 구분선이 생깁니다. 23쪽 문서라면 5·5·5·5·3쪽 파일 5개가 됩니다.

방법 2. 원하는 위치에서 직접 나누기

쪽 카드의 ✂ 버튼을 누르면 그 쪽 바로 뒤에 구분선이 들어갑니다. 챕터 경계처럼 불규칙한 위치에서 나눌 때 편합니다.

방법 3. 파일이 바뀔 때마다 나누기

여러 PDF를 올려 둔 상태에서 “파일이 바뀔 때마다”를 누르면 원본 파일 경계에 구분선이 들어갑니다. 쪽 순서를 섞은 뒤 다시 원래 파일 단위로 정리할 때 씁니다.

파일 이름

한 파일에서 연속된 쪽만 담은 결과는 원본이름_p1-5 형식으로, 여러 파일이 섞이면 이름_01, 이름_02 형식으로 저장됩니다.
