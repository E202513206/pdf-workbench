PDF에서 원하는 쪽만 뽑아내는 방법

수십 쪽 문서에서 필요한 쪽만 골라 새 PDF로 만드는 방법입니다.

범위 입력 문법

입력뜻
55쪽 한 장
1-31~3쪽
1-3, 7, 10-1~3쪽, 7쪽, 10쪽부터 끝까지

쪽 번호는 1부터 시작하며, 범위는 작은 번호를 앞에 적어야 합니다(예: 5-3은 오류).

순서

  1. PDF를 올리고, 자료함의 해당 파일 카드에서 범위 입력칸에 원하는 범위를 적고 “추가”를 누릅니다.
  2. 작업대에 담긴 쪽을 확인합니다. 쪽을 더블클릭하면 크게 볼 수 있습니다.
  3. 불필요한 쪽은 선택 후 “선택 삭제”로 지웁니다.
  4. “저장하기”를 누르면 선택한 쪽만 담긴 새 PDF가 만들어집니다.

원본은 바뀌지 않아요

작업대에서 하는 모든 작업은 복사본에 적용됩니다. 원본 PDF는 그대로 유지되므로 안심하고 시도해 보세요.

이럴 때 유용합니다

  • 계약서·보고서에서 서명 쪽만 따로 제출할 때
  • 교재에서 특정 단원만 인쇄할 때
  • 스캔 묶음에서 불필요한 빈 쪽을 제거할 때
