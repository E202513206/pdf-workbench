사용 가이드

PDF 작업별 단계 설명과 팁을 모았습니다.

PDF 여러 개를 하나로 합치는 방법여러 PDF를 하나로 묶고 쪽 순서까지 자유롭게 바꾸는 방법입니다.PDF에서 원하는 쪽만 뽑아내는 방법수십 쪽 문서에서 필요한 쪽만 골라 새 PDF로 만드는 방법입니다.PDF를 N쪽마다 여러 파일로 나누는 방법하나의 긴 PDF를 일정한 쪽수로 쪼개거나 원하는 위치에서 나누는 방법입니다.PDF 쪽 방향(회전) 바로잡는 방법옆으로 누운 스캔 쪽을 바르게 세워 저장하는 방법입니다.PDF에 쪽번호 넣는 방법합본 PDF에 일련번호를 매겨 인쇄·제출용으로 정리하는 방법입니다.암호가 걸린 PDF가 열리지 않는 이유“암호가 설정된 파일은 처리할 수 없습니다” 메시지가 나올 때 확인할 것들입니다.온라인 PDF 도구의 개인정보 위험과 브라우저 처리 방식내 파일이 서버로 가는지 아닌지, 어떻게 구분하고 확인할 수 있을까요?
