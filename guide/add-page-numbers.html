PDF에 쪽번호 넣는 방법

합본 PDF에 일련번호를 매겨 인쇄·제출용으로 정리하는 방법입니다.

순서

  1. 합치거나 나눈 작업을 마칩니다.
  2. 하단 막대의 “쪽번호 넣기”를 체크합니다.
  3. “저장하기”를 누릅니다.

번호 형식

쪽 하단 가운데에 현재쪽 / 전체쪽 형식(예: 3 / 12)으로 작게 표시됩니다. 파일이 여러 개로 나뉘면 각 파일마다 1부터 다시 매깁니다.

주의

  • 원본에 이미 쪽번호가 있다면 겹쳐 보일 수 있으니 한쪽만 사용하세요.
  • 번호는 영문 숫자로만 표시됩니다.
  • 회전된 쪽은 회전 방향에 맞춰 번호도 함께 돌아가 표시됩니다.

PDF 워크벤치

PDF 합치기·나누기·순서 바꾸기를 브라우저 안에서 처리하는 무료 도구입니다. 파일은 서버로 전송되지 않습니다.
