온라인 PDF 도구의 개인정보 위험과 브라우저 처리 방식

내 파일이 서버로 가는지 아닌지, 어떻게 구분하고 확인할 수 있을까요?

두 가지 방식

서버 업로드형브라우저 내 처리형 (본 사이트)
파일 이동내 기기 → 업체 서버 → 내 기기내 기기 안에서만
유출·보관 위험서버 보관 기간·접근 통제에 의존서버에 없으므로 구조적으로 낮음
속도업로드·다운로드 시간 필요기기 성능에 따라 결정
대용량서버 한도 적용이 흔함기기 메모리 한도

왜 문서 업로드가 위험할 수 있나요?

계약서, 급여·재직 증명서, 신분증 사본, 학생 정보가 담긴 PDF는 한 번 외부 서버로 가면 삭제 여부를 확인하기 어렵습니다. 업체가 “일정 시간 후 삭제”라고 밝혀도 이용자가 검증할 방법은 많지 않습니다.

직접 확인하는 방법

  1. 브라우저에서 F12를 눌러 개발자 도구를 열고 Network(네트워크) 탭을 선택합니다.
  2. PDF를 올리고 합치기를 실행합니다.
  3. PDF 데이터를 담은 큰 업로드 요청(POST)이 없다면 파일이 외부로 나가지 않는 것입니다. 본 사이트는 처음 한 번 라이브러리를 내려받는 요청 외에 파일 전송 요청이 없습니다.

더 안전하게 쓰는 팁

  • 민감한 문서는 작업 후 브라우저 탭을 닫고 다운로드 폴더의 중간 파일을 정리하세요.
  • 공용 PC에서는 작업 뒤 결과 파일을 삭제하세요.
  • 인터넷을 끊어도(라이브러리 로딩 이후) 작동하는지 시험해 볼 수 있습니다.
