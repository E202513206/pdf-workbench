01 — 한 작업대

PDF
합치기·
나누기

섞고, 자르고, 합치기. 여러 PDF의 쪽을 한 작업대에 모아 끌어서 순서를 바꾸고, 구분선을 그어 원하는 만큼의 파일로 저장합니다.

02 — 파일 올리기

PDF를
끌어다 놓기

여러 개를 한꺼번에 놓을 수 있습니다. 합치기와 나누기는 같은 화면에서 모두 가능합니다.

자료함 — 0
작업대 — 0쪽
✂ 구분선 쪽마다 구분선으로 나뉜 묶음이 각각 파일 1개가 됩니다.

PDF 합치기·나누기, 이렇게 쓰세요

별도 프로그램 설치나 가입 없이 네 단계로 끝납니다.

  1. 올리기PDF를 끌어다 놓거나 “파일 선택”을 누릅니다. 여러 개도 한 번에 가능합니다.
  2. 담기자료함의 쪽을 클릭하거나 끌어서 작업대에 놓습니다. “1-3, 5, 8-” 같은 범위 입력도 됩니다.
  3. 정리하기끌어서 순서를 바꾸고, 회전·삭제·복제·빈 쪽 삽입을 합니다. 가위(✂) 구분선으로 나눌 위치를 정합니다.
  4. 저장하기쪽번호 옵션을 고르고 저장합니다. 파일이 여러 개면 ZIP으로 묶어 내려받습니다.

단계별 자세한 설명은 사용 가이드에서 확인하세요.

워크벤치가 다른 점

합치기와 나누기를 따로 하지 않고, 한 작업대에서 한 번에 처리합니다.

  • 섞어서 합치기 — A 파일 3쪽, B 파일 7쪽, 다시 A 파일 5쪽처럼 여러 파일의 쪽을 자유롭게 교차 배치합니다.
  • 구분선으로 나누기 — N쪽마다, 파일이 바뀔 때마다, 또는 원하는 쪽 뒤에 구분선을 넣어 여러 파일로 저장합니다.
  • 되돌리기·다시 실행 — 최대 100단계까지 Ctrl+Z로 되돌릴 수 있어 안심하고 실험할 수 있습니다.
  • 확대 미리보기 — 카드를 더블클릭하면 크게 보며 확인합니다.
  • 키보드 조작 — 카드에서 Space/Enter로 선택, Delete로 삭제, Shift로 범위 선택을 지원합니다.
  • 업로드 없는 처리 — 파일이 서버로 전송되지 않아 계약서·증빙 서류도 부담 없이 다룹니다.

이럴 때 쓰세요

제출 서류 한 파일로신청서·증빙·사본을 순서대로 묶어 한 번에 제출 필요한 쪽만 뽑기수십 쪽 중 서명 쪽이나 특정 단원만 따로 저장 긴 문서 나누기스캔 묶음을 N쪽 단위로 분리해 개별 파일로 눕거나 뒤집힌 쪽 바로잡기스캔 방향을 90도씩 돌려 저장 쪽번호 매기기합본에 “3 / 12” 형식 번호 추가 안전하게 처리하기내 파일이 서버로 가지 않는지 직접 확인하는 법

내 파일은 어디로 가나요?

PDF를 읽고 합치고 나누는 모든 계산은 이용자의 브라우저 안에서 일어납니다. 사이트 서버는 화면을 구성하는 정적 파일만 전달하며 PDF 데이터는 받지 않습니다. 브라우저 개발자 도구의 Network 탭에서 직접 확인할 수 있으며, 방법은 브라우저 처리 방식 가이드에 적어 두었습니다. 작업 내용은 탭을 닫으면 사라지므로 저장 전에는 창을 닫지 마세요.

자주 묻는 질문

정말 무료인가요? 가입이 필요한가요?

무료이며 가입이나 로그인이 필요 없습니다. 쪽수·횟수 제한도 두지 않습니다. 운영비는 광고로 충당할 수 있습니다.

파일이 서버에 저장되나요?

아니요. 파일은 이용자의 브라우저 메모리에서만 처리되고 서버로 전송되지 않습니다.

암호가 걸린 PDF는 왜 안 되나요?

암호 없이는 내용을 읽을 수 없기 때문입니다. 정당한 권한이 있다면 뷰어에서 암호를 풀어 열고 “PDF로 인쇄”해 만든 사본을 올리세요. 자세히

몇 MB, 몇 쪽까지 되나요?

정해진 제한은 없지만 기기 메모리에 따라 달라집니다. 수백 MB 파일이나 수천 쪽 문서는 느리거나 실패할 수 있으니 나누어 작업하세요.

합치면 화질이 떨어지나요?

아니요. 원본 쪽을 그대로 복사하므로 화질·글자·링크 품질이 유지됩니다. 미리보기 썸네일만 저화질입니다.

쪽 순서를 잘못 바꿨어요.

Ctrl+Z(Mac은 Cmd+Z) 또는 “되돌리기” 버튼으로 되돌립니다. Shift를 더해 누르면 다시 실행합니다.

스마트폰에서도 되나요?

최신 Chrome·Safari 등에서 사용할 수 있습니다. 쪽 끌어서 놓기는 PC가 편하며, 모바일에서는 ‹ › 버튼으로 순서를 옮길 수 있습니다.

결과 파일이 여러 개로 나와요.

작업대에 구분선(✂)이 남아 있기 때문입니다. “모두 지우기”를 누르면 한 파일로 저장됩니다.

오류나 제안은 어디에 알리나요?

운영자 문의 페이지의 이메일로 보내 주세요.
